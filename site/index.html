How it works

Three steps, all on your Mac.

  1. Your agent works as usual.

    As Codex works on your project, BORG saves useful facts from each session, for example which tools you use and what you decided.

  2. BORG files it away.

    Notes go into a private memory in one folder on your Mac. Small AI models, also on your Mac, sort the notes and link related facts.

  3. Next time, it remembers.

    When Codex starts a task, BORG hands it the notes that matter for that task.

OpenAI's coding agent. You talk to it in Terminal and it writes and runs code for you. is connected for you during setup. Anthropic's coding agent for Terminal. and Grok connect with a few extra steps, then search the same memory.

What you get

One install. Three parts.

  1. 1

    Memory

    Saves what your agents learn and finds the right note again, even when you word it differently.

    Semantic memory (mem0 with Qdrant) and a temporal knowledge graph (Graphiti with FalkorDB), run by local models through Ollama.
  2. 2

    Tools

    Lets your agents work on your Mac: open files, run commands, run long jobs and use their own browser. macOS asks you before an agent can control other apps.

    A native MCP connector with file, command, durable-job, browser and desktop tools.
  3. 3

    Teamwork

    Your agents can message each other and keep one shared task list, so everyone can see what's done and what's next.

    Agent Inbox for messages and assignments, Beads for the task graph, and a conductor that runs agent work.

Also included, and switched off: three small trained models for research.

Get started

Let your AI set it up.

The easiest way: give your AI agent the instructions and let it do the typing. The message below asks it to check your Mac first and explain each step before it runs it.

Let your AI do it

  1. Open Codex or Claude Code in An app on every Mac for typing commands. Press ⌘ and Space, type Terminal, then press Return..

    Use the AI coding agent you already have.

  2. Paste this message.
    Message for your AI agent

    Read https://borg.utlyze.com/llms.txt and the installation runbook it links to. Help me install BORG on this Mac. Check my Mac first, explain each step in plain words before you run it, use my own accounts, and tell me what works and what still needs setup.

  3. Answer its questions.

    It installs BORG, helps you sign in to Codex and tells you what works.

Type it yourself

In the third line, replace yourname with a short lowercase name for you, like jamie.

A short lowercase name for you, like jamie. BORG uses it as your owner ID. We fill it into the commands below.

Terminal · paste all six lines
  1. git clone https://github.com/h3ro-dev/borg.gitDownloads BORG.
  2. cd borgMoves into its folder.
  3. ./install.sh --owner yournameInstalls BORG into ~/.borg, with its local AI models.
  4. "$HOME/.borg/bin/borg" onboardShows your next steps.
  5. "$HOME/.borg/bin/borg" auth codexSigns you in to Codex with your own account.
  6. "$HOME/.borg/bin/borg" doctorChecks what's working.

Good to know

Questions people ask first.

Is BORG free?

Yes. BORG is open source under the MIT license. You use your own AI accounts, such as the one you use for Codex, and their normal costs apply.

Where is my data stored?

On your Mac, in one private folder (~/.borg). BORG never connects to our setup or to anyone else's.

When your AI uses a memory, that note becomes part of your chat with that AI's company, like anything you type.

Will it slow down or change my Mac?

BORG runs several background services that only your Mac can reach. Its local AI models use memory, so a Mac with more memory runs it more comfortably.

macOS asks your permission before an agent can control other apps or see your screen.

Which AI tools work with it?

Codex is connected during setup. Claude Code and Grok work after a few extra steps in the install guide. ChatGPT on the web can connect too, through your own Cloudflare account. That one is for advanced users.

Do I need to know how to code?

You need to be comfortable pasting commands into Terminal, or letting your AI agent do it for you.

How do I remove it?

Stop BORG, then remove its folder and its background services. The install guide explains how, including backing up first.
